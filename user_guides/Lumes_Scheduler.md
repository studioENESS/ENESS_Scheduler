# User Guide
> ENESS Lumes Scheduler

Pictured Below is how the scheduler will look while it is Running:

![/Picture-01](/user_guides/Lumes_Scheduler_img/image5.png)

At the top of the window you will see if the Scheduler has detected a running instance of the Lumes wall software. Pressing the “Restart Lumes” Button will End the current Running Instance and relaunch it.

![/Picture-02](/user_guides/Lumes_Scheduler_img/image6.png)

1. The Scheduler controls the time of day that the content will start running from, and what time of day  the content will run to. These are set with the Starting Time, and Ending Time combo Boxes. The Left Box is the Hour, the Right Box is the Minute.
2. The current running Content, is listed on the scheduler as well, as you can see it is currently set to be running the “New England Winter” scene.
3. The Time is in 24 Hour format. The Default settings for this is for the software to start at 6:00am and End at 10:00pm.

![/Picture-03](/user_guides/Lumes_Scheduler_img/image2.png)

4. `Load Schedule` loads in the last saved schedule, This can be used to reset the values to what they were when the software was loaded, or the lasted saved schedule.
5. `Save Schedule` Saves the modifications that you have done to the current schedule, this includes the Starting Time, and Ending Time.
6. `Add Schedule Item` Adds a new item to the schedule list.

![/Picture-04](/user_guides/Lumes_Scheduler_img/image1.png)

7. Above is the list of the currently setup schedule. There are currently 12 items in the list one for each month of the year, which also corresponds to one of the Content Scenes inside the Lumes software since there are 12 different content scenes in the Lumes software you have been provided with..
8. The current Active Schedule is Highlighted, and Has the Word Active behind it.
9. Clicking on the Arrow to the left of a schedule item expands it out to the following window.

![/Picture-05](/user_guides/Lumes_Scheduler_img/image4.png)

10. Here you are able to change the Dates that the content runs from, and which content it currently is set to. 
11. Changing the program of the Currently Active Schedule Item, will also change what is currently running on the Lumes Wall. This happens instantly.

![/Picture-06](/user_guides/Lumes_Scheduler_img/image3.png)

12. Clicking on the Down arrow next to either the Scheduled Starting or Ending Date will make a Date Selection Popup appear. Here you are able to set the Start and End Day of the Selected Content.

> **Note** If the End Date of the Content is set After the Starting Date of the Next Item in the List it will have precedence over any content following it.
I.E: If you changed the End date of the First Content, “New England Winter” to the 3rd of Feburary, then it will run until the 3rd of Feburary, and the Second set of Content will not start until the 4th of Feburary, even though its start date is set to be the 1st of Feburary.
